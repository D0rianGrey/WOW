# Бэклог после финального аудита — 2026-09-17

Пробелы, которые нашёл фактчек Grok по живому сайту. Все закрываются официальным текстом,
который уже зарегистрирован в реестре источников или доступен по открытой ссылке. Ни один
пункт не требует догадок о сюжете.

Порядок работы для каждого пункта — `docs/automation/lore-update-contract.md`: цитаты в реестр,
`npm run verify:evidence`, контент, записи в журналы, PR.

## 1. Досье персонажей кампании Forsaken Kingdom

**Важность: высокая.** Официальный recap кампании называет по именам фигуры, у которых в
энциклопедии нет карточек: Putress, Varimathras, Sally Whitemane, Renault Mograine,
Ras Frostwhisper, Baron Rivendare.

- Источник: `forsaken-kingdom-whats-next` (уже в реестре), цитата `ds-r1-106` — она перечисляет имена.
- Что писать: имя, роль по официальному тексту, статус `FOREVER`, явная оговорка, что сюжетная
  роль в кампании официально не пересказана.
- Не додумывать: исходы кампании, судьбы, мотивацию.
- Отдельной регистрации ID больше не требуется: реестр сущностей выводится из самих досье.

## 2. Досье лидеров первого года, которых главы уже называют

**Важность: высокая.** В главах упомянуты, но карточек нет: Fandral Staghelm, Gelbin Mekkatorque,
Magni Bronzebeard, Vol’jin.

- Источник: мануал 2004 года (`world-of-warcraft-2004-manual`) — уже в реестре, цитаты про каждого
  из них в реестре тоже есть (ищи по `entryRefs` глав 05 и 07).
- Статус `ESTABLISHED`; поздний Retail не тянуть.

## 3. Статьи о восьми играбельных расах первого года

**Важность: высокая.** Есть фракции Alliance и Horde и раса Skyborne, но нет ответа на вопрос
«кто такие dwarves в первый год».

- Источник: мануал 2004, приложение II *Races in Conflict*.
- Решение до начала: отдельная коллекция `races` или досье внутри `factions`. Рекомендация —
  отдельная коллекция: у рас свои поля (столица, стартовая зона, доступные классы), и они уже
  описаны цитатами про стартовые зоны (`fv-07`…`fv-12`).

## 4. Карточки фракций Forever: Powderfuse goblins и Brotherhood of the Horse

**Важность: средняя.** Названы в Found Photos рядом с Twilight’s Hammer, но карточек нет, хотя
Windshapers, High Order и Al’Aketh их имеют.

- Источник: `forever-found-photos` (в реестре).
- Оговорка обязательна: кроме названия и связи с Riverglades ничего официально не сказано.

## 5. Страницы мест для подземелий и рейдов Forever

**Важность: средняя.** Девять подземелий и два рейда существуют только списком на
`/forever-changes/`. Для читателя нет страниц Hall of Thanes, Ruins of Lordaeron (как подземелья),
Barrow Deeps и Hyjal Summit.

- Источники: `forever-whats-next` и blue-post `forever-dungeon-levels` (оба в реестре) —
  у подземелий теперь есть официальные имена и диапазоны уровней.
- Аккуратно: Ruins of Lordaeron как подземелье и Lordaeron как королевство — разные записи.

## Что сознательно не делаем

- Наблюдения с беты Forever. Ждём официального или внутриигрового текста — статус `BETA`,
  ревью человека (контракт, слой 2).
- Датамайн и пресс-интервью без открытой официальной страницы с дословной цитатой.
- Вторая версия порядка событий пути в Kalimdor: нужна проверенная цитата, пока её нет.

# Технический бэклог

Находки архитектурного ревью, которые осознанно отложены. Ни одна не мешает работе сайта сегодня.

| Что | Почему отложено | Первый шаг |
|---|---|---|
| Разбить `docs/research/evidence/dossiers.json` по сущностям | Механическая, но объёмная правка; после схлопывания дублей файл стал заметно меньше и терпим | Переименовать ID по сущности (`arthas-01` вместо `ds-r1-01`) и разложить по файлам; скрипт и тест читают папку рекурсивно |
| `eraId` во frontmatter вместо свободной строки `era` | Затрагивает все записи контента и вывод заголовков | Добавить `eraId: z.enum(eraIds)` рядом с `era`, заполнить, потом удалить `era` |
| Одна страница досье вместо трёх почти одинаковых | Дублирование терпимое, риск регрессии выше выгоды прямо сейчас | `DossierPage.astro` с пропом `collection`; три маршрута только передают его |
| Честная дата проверки источников (`checkedAt`) | Сейчас дата ставится руками и не обновляется — читатель видит «проверено 2026-09-17» бесконечно | Шаг CI пишет дату из отчёта `verify:evidence` (единственное разрешённое автоизменение) |
| Тесты самого загрузчика доказательств | Логика защиты есть, тестов на неё нет | Юнит-тесты на `assertPublicUrl`, лимит размера и цепочку редиректов на локальном сервере |
| Карты мест (спека §12) | Крупная работа, ценность оценивает владелец | Решение: либо явно перенести в отложенное в спеке, либо отдельная задача V1.1 |
| `id` и `slug` — два поля, которые всегда совпадают | Пока не расходились | Либо убрать `slug`, либо `refine(id === slug)` |
| ID цитат назначаются вручную (`ds-r1-01`, `ch07-…`) | При 1500 цитатах «следующий свободный номер» ищется глазами | ID из содержания: `<sourceId>-<короткий хеш цитаты>` |
| У реестра доказательств нет zod-схемы: форма описана в README, тесте, скрипте и на странице источников | Проверки есть, но в четырёх местах и по-разному | `ledgerEntrySchema` в `src/lib/content.ts`; тест и страница импортируют её |
| Обход ссылок в e2e стартует с главной: страница, на которую никто не ссылается, не проверяется | Сейчас таких страниц нет | Сравнивать число обойдённых страниц с числом `index.html` в `dist/` |
