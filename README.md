# World of Warcraft: Forever — энциклопедия

Статический русскоязычный справочник по миру Warcraft, созданный на Astro и подготовленный для публикации в GitHub Pages по адресу `/WOW`.

## Команды

- `npm run dev` — локальная разработка.
- `npm run build` — проверка типов и статическая сборка.
- `npm run preview` — просмотр готовой сборки.
- `npm run test` — модульные тесты.
- `npm run test:e2e` — браузерные тесты против собранного сайта (`astro preview`).
- `npm run verify:evidence` — сверка всех цитат реестра доказательств с живыми официальными источниками (нужна сеть).

Каждый факт в главах подкреплён дословной цитатой официального источника: см. `docs/research/evidence/README.md`.
